# Консольный набор утилит
#### Python-пакет с CLI, содержащий калькулятор и конвертер величин.
## Скачивание и подготовка к использованию
1. Склонируйте или скачайте проект к себе
2. Создайте виртуальное окружение:
 - Введите в консоль команду `uv venv`. 
 - Затем пропишите `.venv/bin/activate`.
3. Установите pip в venv:
 -  `python -m ensurepip --upgrade`
4. Скачайте зависимости командой
 - `python -m pip install -r requirements.txt`
5. Перейдите в директорию lab_01:
 - `cd lab_01`
6. Используйте команду `uv pip install -e . `
#### После этого пакет доступен в консоли как CLI-утилита.

## Калькулятор
1. Для запуска калькулятора используйте команду:
 - `python -m toolkit calc '{expression}'` <br/>
Вместо {expression} введите искомое выражение для подсчета
2. Для запуска тестов, находясь в директории lab_01 ведите команду:
 - `python -m pytest tests/calculator_pytest.py `

## Конвертер
1. Для запуска конвертера используйте команду:
 - `python -m toolkit converter '{value_to_convert}' --from '{unit_from}' --to '{unit_to}'` <br/>
Вместо {value_to_convert} введите значение для конвертации. <br/>
Вместо {unit_from} - еденицу измерения, из которой хотите перевести. <br/>
Вместо {unit_to} - еденицу измерения, в которую хотите перевести
2. Для запуска тестов, находясь в директории lab_01 ведите команду:
 - `python -m pytest tests/converter_pytest.py `
